# Changelog

- Bundled the complete offline King James Bible.
- Added a read-only SQLite Bible database containing 31,102 verses.
- Replaced duplicated daily verse text with 1,095 reference-only reading plans.

- Made the Android build self-contained and deterministic.
- Added SQLite integrity, verse-count, reference-resolution, and cycle validation.
- Retained Daily Verse as the true launcher Home page.
- Retained seven-day history, favourites, Minimal Mode, accessibility settings, and double-tap lock.
